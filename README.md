# Data Science Practice (CS5830)

Exploratory data analysis practice using the [Lahman Baseball Database](http://www.seanlahman.com/baseball-archive/statistics/).

## Contents

- [`Assignment1_baseball_dataset/hall_of_fame_roles.ipynb`](Assignment1_baseball_dataset/hall_of_fame_roles.ipynb) — exploration of the Hall of Fame voting data (`core/HallOfFame.csv`).
- [`Assignment1_baseball_dataset/core/`](Assignment1_baseball_dataset/core/) — Lahman Baseball Database CSV tables (2014 release).
